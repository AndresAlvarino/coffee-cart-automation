# Coffee Cart - Pruebas Automatizadas

Este proyecto simula una tienda en línea de café e incluye pruebas automatizadas con Selenium y Python.

## Estructura
- `src/` - Código fuente de la aplicación
- `tests/` - Pruebas automatizadas con Selenium
- `screenshots/` - Evidencias gráficas de las pruebas

## Requerimientos
- Node.js
- Python 3.13
- Google Chrome
